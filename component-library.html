Choose a Pattern

한 섹션에서 전달할 내용을 먼저 정합니다. 긴 설명은 문단으로 읽히게 하고, 비교·수치·조작이 필요한 지점에 해당 패턴을 추가합니다.

내용에 따른 패턴 선택 기준
전달할 내용사용할 패턴작성 기준
선택한 이유·과정일반 문단문제 → 판단 → 근거 순서. 배경 패널은 필요한 요약에만 사용.
환경·범위·주의점정보 패널짧고 독립적인 정보 묶음. 전체 본문을 패널로 감싸지 않음.
품질·구현 차이비교 이미지같은 시점·구도·조건인지 밝히고 각 이미지에 캡션 제공.
측정 결과수치 표단위·환경·측정 범위 필수. 근거가 없으면 관찰한 결과를 문장으로.
시간에 따른 변화조작 가능한 영상핵심 동작을 짧게 보여주고 설명·원본 링크 제공.
프로젝트 목록이미지 카드결과물 + 한 문장 소개. 카드 전체는 상세 페이지로 연결.

새 페이지는 상세 템플릿에서 시작합니다. 코드의 [REPLACE], 경로, 번역, 샘플 수치를 교체한 후 완료 기준을 확인하세요.

Colors

현재 미리보기: 라이트. 색상칩은 공통 CSS 변수에 연결되고 HEX는 그 변수의 현재 값을 읽어 표시합니다. 예: text-muted → --c-muted.

적용 후 완료 기준

  • 390px·768px·데스크톱에서 긴 한·영 제목, 표, 코드가 페이지 전체를 가로로 밀지 않는다.
  • Ko/En 전환 후 내용·폰트가 맞고, 카드·메뉴·이미지 확대가 동작한다.
  • Tab/Enter로 링크와 버튼을 조작하고, Escape로 이미지 뷰어를 닫으면 원래 링크로 돌아온다.
  • [REPLACE]·샘플 수치·샘플 미디어를 교체하고 측정 조건·담당 범위를 확인한다.
  • python3 scripts/build_site.py로 공개 페이지의 경로·앵커·h1 검증을 통과한다.

이 체크리스트는 적용 확인 항목입니다. 전체 접근성 적합성을 인증하는 것은 아닙니다. 현재 한계와 규칙도 함께 확인하세요.
